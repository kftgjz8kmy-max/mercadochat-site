# merchat landing page

Single-page marketing site for **merchat**, built with Vinext, React,
TypeScript, Tailwind CSS, and the App Router.

## Rebrand and content

The landing page content is centralized for simple maintenance:

- `config/site.ts` — product name, contact link, colours, and navigation.
- `config/landing.ts` — page copy, example conversations, features, pricing,
  trust points, and FAQs.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
npm test
```
