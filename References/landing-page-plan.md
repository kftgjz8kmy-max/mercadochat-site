# ML-Automation — Plan de landing page

## Objetivo

Crear una landing page de una sola página, basada en **minimalismo informativo**, para que un visitante entienda en menos de 10 segundos:

1. Qué es el producto.
2. Qué puede hacer.
3. Para quién está pensado.
4. Cómo solicitar una demostración.

El producto se presenta comercialmente como un **asistente IA para vendedores de Mercado Libre**, no como un “MCP”.

## Mensaje principal

### Título sugerido

**Gestiona Mercado Libre hablando con una IA**

### Subtítulo

Consulta ventas, revisa órdenes, investiga productos y prepara publicaciones utilizando lenguaje natural.

### Llamadas a la acción

- Solicitar demo
- Ver cómo funciona

La acción principal debe dirigir a WhatsApp o a un formulario breve.

---

## Estructura de la página

### 1. Hero

Debe ocupar la primera pantalla y contener:

- Título principal.
- Subtítulo corto.
- Botón principal: **Solicitar demo**.
- Botón secundario: **Ver cómo funciona**.
- Mockup grande de una conversación real con el asistente.

Ejemplo de conversación:

**Usuario:** ¿Cuáles fueron mis productos más vendidos esta semana?

**Asistente:** Vendiste 47 unidades. Tus tres productos principales fueron…

La primera imagen debe mostrar el producto funcionando, no una fotografía genérica.

### 2. Slider visual dinámico

Crear un carrusel horizontal con tarjetas grandes, bordes redondeados y desplazamiento suave. Debe mezclar:

- Capturas de chats.
- Mockups del sistema.
- Imágenes de vendedores o equipos.
- Resultados y casos de uso.

Contenido sugerido:

1. Chat: “¿Cuánto vendí hoy?”
2. Chat: “Muéstrame mis últimas órdenes.”
3. Imagen de vendedor o equipo trabajando.
4. Chat: “¿Qué producto vendí más esta semana?”
5. Mockup de una publicación.
6. Chat: “Compara mi precio con publicaciones similares.”
7. Imagen de tienda o agencia.
8. Chat: “Prepara una publicación para este producto.”

Comportamiento:

- Movimiento automático lento.
- Pausa al colocar el cursor.
- Arrastre manual con mouse.
- Deslizamiento táctil en móvil.
- Cada tarjeta puede abrirse ampliada.
- Una sola idea por tarjeta.

### 3. Capacidades principales

Mostrar solo cuatro capacidades, en tarjetas pequeñas:

#### Consulta tus ventas

Obtén ventas, productos, precios, operaciones y estados en segundos.

#### Revisa tus órdenes

Encuentra pedidos recientes, pendientes o relacionados con un producto.

#### Investiga el mercado

Compara productos, publicaciones y precios antes de tomar decisiones.

#### Gestiona publicaciones

Prepara o crea publicaciones con información estructurada y confirmación previa.

Solo deben mostrarse como disponibles las funciones que ya estén estables. Las demás pueden marcarse como “Próximamente” o “Beta”.

### 4. Cómo funciona

Tres pasos:

1. **Conecta tu cuenta** mediante autorización oficial de Mercado Libre.
2. **Haz una pregunta** sobre ventas, órdenes, publicaciones o productos.
3. **Recibe información o confirma una acción** antes de realizar cambios importantes.

### 5. Planes

#### Vendedor medio

- Precio sugerido: **S/149 mensuales**.
- Implementación única: **S/249**.
- Una cuenta de Mercado Libre.
- Consultas de ventas y órdenes.
- Información de productos, precios y estados.
- Consulta de publicaciones propias.
- Investigación básica de productos.
- Creación asistida de publicaciones.
- Soporte estándar.

#### Vendedor fuerte

- Precio sugerido: **S/299 mensuales**.
- Implementación única: **S/499**.
- Plan recomendado visualmente.
- Incluye todo el plan Vendedor medio.
- Mayor volumen de consultas.
- Investigación frecuente de productos y precios.
- Comparación de publicaciones.
- Uso recurrente para crear publicaciones.
- Configuración personalizada para la tienda.
- Capacitación inicial.
- Soporte prioritario.
- Revisión mensual de funcionamiento.

#### Agencia

- Precio sugerido: **desde S/749 mensuales**.
- Implementación: **desde S/1,200**.
- Hasta tres cuentas de Mercado Libre.
- Separación de información por cliente.
- Configuración independiente por cuenta.
- Consultas y acciones por cliente.
- Capacitación para el equipo.
- Incorporación asistida de nuevas cuentas.
- Soporte prioritario.
- Cuenta adicional: **S/150 mensuales**.

### 6. Seguridad y confianza

Título sugerido:

**Tu cuenta y tus datos permanecen protegidos**

Puntos breves:

- Conexión oficial mediante autorización de Mercado Libre.
- Cada usuario accede únicamente a sus cuentas.
- Separación de datos entre clientes.
- Confirmación antes de acciones importantes.

No mostrar diagramas técnicos de OAuth, Vercel, base de datos o arquitectura en la landing principal.

### 7. Preguntas frecuentes

1. ¿Necesito conocimientos técnicos?
2. ¿El sistema puede publicar productos?
3. ¿Puede modificar información sin mi permiso?
4. ¿Puedo conectar varias cuentas?
5. ¿Cómo comienzo?

### 8. Cierre

Título sugerido:

**Convierte tu cuenta de Mercado Libre en una herramienta que puedes consultar con IA**

Texto:

Solicita una demostración y descubre cómo reducir el trabajo manual de tu operación.

Botón:

**Solicitar demostración por WhatsApp**

## Materiales necesarios

- Nombre comercial definitivo.
- Logo simple.
- Un color principal de marca.
- Un mockup principal del sistema.
- Seis conversaciones reales o simuladas.
- Seis capturas visuales de chats.
- Dos o tres imágenes de vendedores, tiendas o equipos.
- Número o enlace de WhatsApp.
- Correo comercial.
- Lista final de funciones estables.
- Lista de funciones beta o en desarrollo.

No se necesitan muchas imágenes. Para conservar el minimalismo:

- 6 chats.
- 1 mockup principal.
- 2 imágenes humanas.
- 1 imagen de agencia o equipo.

---

## Reglas visuales

- Fondo blanco o gris muy claro.
- Texto negro o gris oscuro.
- Un solo color de acento.
- Mucho espacio vacío.
- Títulos grandes y textos cortos.
- Tarjetas con bordes redondeados.
- Sombras suaves.
- Sin fondos recargados.
- Sin exceso de iconos.
- Animaciones lentas y discretas.
- Diseño adaptado a móvil.
- Una sola idea por sección.
- Máximo dos botones visibles por sección.

El slider puede ser la parte más visual; el resto debe permanecer sobrio.

## Orden de trabajo

### Fase 1: Contenido

1. Definir el nombre del producto.
2. Confirmar las funciones disponibles.
3. Confirmar precios.
4. Crear seis conversaciones de ejemplo.
5. Redactar las respuestas del sistema.
6. Cerrar las preguntas frecuentes.

### Fase 2: Material visual

1. Diseñar el logo.
2. Crear el mockup principal.
3. Crear seis imágenes de chat.
4. Seleccionar dos o tres imágenes humanas.
5. Mantener el mismo estilo visual en todas las piezas.

### Fase 3: Construcción con Kimi

1. Crear la landing page.
2. Incorporar el slider.
3. Añadir los planes.
4. Conectar los botones con WhatsApp.
5. Optimizar la versión móvil.
6. Publicar en Vercel.

### Fase 4: Validación

1. Probar en iPhone, Mac y Windows.
2. Revisar todos los botones.
3. Comprobar velocidad de carga.
4. Confirmar que el mensaje se entiende en 10 segundos.
5. Mostrar la página a tres vendedores antes del lanzamiento.
